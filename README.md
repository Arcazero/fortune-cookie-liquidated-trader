One original fortune-cookie line for a crypto trader who has just been liquidated, written for make.fun's "Fortune Cookie for the Liquidated Trader" bounty.

The fortune:

> Fortune favours the bold; tonight it favoured the exchange that liquidated you.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
